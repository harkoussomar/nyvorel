# Nyvorel Shell

Nyvorel is a custom Hyprland and Quickshell desktop shell, originally based on
end-4/dots-hyprland and extensively redesigned with its own modules, workflows,
services, UX, and tooling.

> This tree is an open-source staging candidate. It is not yet the final
> release repository or installer.

## Source layout

- `quickshell/` — Nyvorel Quickshell source
- `hypr/` — Hyprland integration/configuration
- `systemd/` — portable user-unit templates
- `bin/` — Nyvorel helper executables
- `integrations/` — application/terminal/shell integrations
- `assets/` — Nyvorel brand assets
- `runtime-config/` — notes for generated user/runtime configuration

## Upstream

Nyvorel is derived from end-4/dots-hyprland. Upstream attribution and GPL-3.0
compliance must remain part of the public release.
